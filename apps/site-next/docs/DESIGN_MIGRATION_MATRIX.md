## Docs implementation

Docs must share the RougeChain wordmark, palette, fonts, spacing, links/buttons, borders, code treatment, status semantics and header/footer/mobile conventions. It may use CSS variables, font/logo/SVG assets and generated theme values from brand tokens instead of React components. Preserve technical readability, search and existing slugs. A different runtime is acceptable; an unrelated visual theme is not.

## Retirement and review

Legacy glass cards, aurora blobs, scanlines/beams, HUD corners, animated rings, jelly logo motion, text shimmer, universal glow/hover lift and multicolor icon tiles should retire as their last dependent screen migrates. Do not remove dependencies still needed by unmigrated production screens. Review [per-app design checklists](DESIGN_COVERAGE_CHECKLISTS.md) and [production acceptance](PRODUCTION_ACCEPTANCE_CHECKLIST.md).
