## Deep-link contract

`rougechain.io/block/24829?network=mainnet` → `explorer.rougechain.io/block/24829?network=mainnet`.
`rougechain.io/pool/abc123?tab=positions` → `swap.rougechain.io/pool/abc123?tab=positions`.

Preserve encoded path parameters, query multiplicity/order where semantically relevant, fragments/bookmarks, locale and network selectors. Do not concatenate unvalidated user-supplied hosts or introduce open redirects. Test refresh, malformed IDs, unknown routes and old bookmarks on the actual target origin. HTTP redirects do not send fragment values to the server; test browser fragment preservation explicitly.

Deploy and verify destinations before old-route redirects. Use a reversible rollout before permanent/cached redirects; lead developer chooses status codes and hosting rules. Define fallback routing, error behavior and rollback owner. Wallet redirects are blocked until old-origin vault access, migration, recovery and rollback are solved. The POC `_redirects` file is only a same-origin SPA fallback and is not this migration implementation.

New production local routes such as Wallet asset/send/receive, Explorer search/network, Swap positions and Bridge history are required product surfaces, but their precise path design must follow the production feature inventory; do not invent legacy equivalents.
