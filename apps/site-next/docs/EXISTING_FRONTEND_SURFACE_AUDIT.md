# Known frontend surface audit

Scope: every route in the final user brief, the POC marketing/workspace surfaces and known external navigation destinations. Current purposes derive from the supplied route inventory and approved POC; **the production router was not inspected and runtime feature completeness was not verified**. This is a complete classification of known surfaces, not a claim that no undiscovered route exists. Lead developer must reconcile against the production router and multilingual variants before redirect rollout. No production repository was cloned or recursively searched.

Design migration is required for every active internal surface. External products receive an explicit owner/design alignment review; this handoff does not claim authority over their code or third-party store chrome. No surface is marked retired without an owner decision. Migration status below means remaining production work, not completed deployment.
